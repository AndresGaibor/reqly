# Átomo: insignia de estado

## Propósito

Mostrar el estado de un requisito, un caso de uso o un ticket.

## Anatomía

Icono opcional, texto y fondo.

## Variantes

- formal: texto color.text.secondary, sin icono.
- revisado: texto color.feedback.success.text, con icono de verificado.
- retirado: texto color.text.secondary tachado, con icono de retirado.
- hueco: texto color.feedback.error, con icono de advertencia y el texto "Hueco".

## Radio

4 px.

## Accesibilidad

El icono y el texto siempre van juntos. Nunca una insignia de color sin texto.

## Reglas de uso

Una insignia por elemento y estado.
